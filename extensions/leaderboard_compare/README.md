# Leaderboard Compare v0.2.1

`leaderboard_compare` is a Rank Hunter **Analysis** workspace for comparing the
smallest known high-rank curves in the local Rank Hunter database with the
locally synchronized ICARM Elliptic Curve Rank Leaderboard snapshot.

This release is the renamed successor to **ICARM Charts v0.1.1**. The plugin
identity, folder, manifest id, workspace label, runtime module names, CSS hooks,
and widget keys now use **Leaderboard Compare**.

## Theme support

The chart, legend, table, empty states, notes, and comparison markers consume
Rank Hunter's semantic `rh-*` theme tokens instead of a fixed dark palette.
They therefore follow the active Light/Dark appearance.

All plugin input controls are native Streamlit widgets and continue to receive
Rank Hunter's native Light/Dark palette. Leaderboard Compare also applies a
plugin-scoped semantic-token layer to its radio, slider, selectbox, multiselect,
and checkbox surfaces so their text, borders, selected tags, slider handles,
and input text stay aligned with the active theme.

## Torsion groups

Leaderboard Compare can restrict the comparison to a single rational torsion
group. Rank Hunter rows use the exact stored `curves.torsion_label` generated by
Rank Hunter's torsion enrichment. ICARM rows use the source-provided `torsion`
invariant factors preserved in each synchronized row's `raw_json`.

The filter is deliberately evidence-preserving: it never recomputes or guesses a
torsion group. Rows with missing torsion metadata remain visible under **Any**
and are excluded when a specific group is selected. Torsion is also shown in
chart tooltips, best-record captions, and the plotted-row table.

## Default view

- metric: **log conductor**;
- rank lower bound: **17 and up** when the database contains rank 17+ rows;
- view: **best per rank**;
- Rank Hunter points use the active primary theme color;
- ICARM points use the active muted theme color.

## Plot modes

**Best per rank** keeps the lowest selected metric in each rank column,
separately for Rank Hunter and ICARM.

**Record frontier** keeps source records: a point remains only when no curve
from the same source with an equal-or-higher rank lower bound has a smaller
value.

**All curves** plots every row with the selected metric.

Filters cover rank range, source, rational torsion group, Rank Hunter family,
and an optional local-exact-rank-only switch.

## Metrics

- **log conductor**: natural log of the recorded conductor `N`.
- **naive height**: imported ICARM value.
- **Faltings height**: imported ICARM value.
- **log |Δ|**: natural log of the absolute recorded discriminant.

Rank Hunter's current `curves` table stores conductor and discriminant but does
not persist ICARM-normalized naive/Faltings heights. Local points are therefore
omitted on those two height tabs rather than displaying a non-equivalent proxy.

## Evidence and provenance

For Rank Hunter rows, the plotted rank lower bound follows the strongest stored
value among `exact_rank`, `descent_lower`, and `generic_lower`. An
`exact_rank` is labeled `rank = r`; otherwise the chart says `rank ≥ r`.

ICARM rows come only from Rank Hunter's local `external_curves`
synchronization. They remain external reference data. The plugin never upgrades
local evidence, changes pruning, or treats an ICARM record as a Rank Hunter
discovery.

The presentation and leaderboard idea are inspired by ICARM's open-source
Elliptic Curve Rank Leaderboard. Leaderboard Compare independently implements
its comparison/frontier view for Rank Hunter's plugin API.

# Jaswal C6 generic rank four

Jaswal, *Elliptic curves with torsion group Z/6Z and generic rank four* (2026), [source](https://doi.org/10.5281/zenodo.23735797), Theorem 1.1.

The plugin implements the paper's degree-16 rational map `c(t)` into the universal C6 model `y²=x³+(1+6c−3c²)x²−16c³x`, with torsion point `(-4c,4c(1+c))`. The paper proves exact generic rank four, exact C6 torsion, and an exact-rank-four fiber at `t=13/6`. The four generic free sections and their independence proof remain in the paper; the plugin records the rank as a historical claim, not a local certificate.

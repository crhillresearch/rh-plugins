# Jaswal C2 × C6 genus-one family

Source: [Jaswal, *Infinitely many elliptic curves with torsion Z/2Z × Z/6Z and rank at least four* (2026)](https://doi.org/10.5281/zenodo.23364157).

The model and genus-one quartic are transcribed from the paper's formulas as used in `research/c2x6_jaswal_rank4_cover_scan.py`. The paper proves four independent sections and infinitely many exact-torsion fibers. This package records the historical rank claim; a machine-checkable rank certificate is not included.
